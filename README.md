# 🎮 GameCraft

**Learn. Build. Play.** — A customizable DIY game console built on Arduino Nano, 
a 128x64 OLED display, and a single push-button — powered by 4 AA batteries.

GameCraft is an open-source collection of classic-inspired arcade games, 
designed to teach embedded systems, game logic, and electronics through 
hands-on play. Perfect for STEM education, maker fairs, and DIY enthusiasts.

## 🛠️ Hardware Required
- Arduino Nano
- SH1106 / SSD1306 128x64 OLED Display (SPI)
- 1x Push Button
- 4x AA Battery Pack
- Jumper wires, breadboard/PCB

## 🕹️ Games Included
| Game | Genre | Mechanic |
|---|---|---|
| Flappy Bird | Arcade | Tap to fly |
| Stop The Bar | Reflex | Precision tap |
| Memory Beep | Memory | Short/long press sequence |
| Rhythm Tap | Rhythm | Timed tapping |

## 📦 Installation
1. Install Arduino IDE
2. Install libraries: `Adafruit_GFX`, `Adafruit_SH110X`
3. Select the game `.ino` file you want to flash
4. Upload to Arduino Nano
5. Power via USB or 4xAA battery pack

## 🎯 Why GameCraft?
- Learn C++ & embedded programming through fun projects
- Single hardware setup, multiple game genres
- Fully open-source — modify, remix, and create your own games
- Great for classrooms, workshops, and maker events
